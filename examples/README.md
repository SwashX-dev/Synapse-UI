# Extension examples

Import a folder with the Module Manager, review requested capabilities, approve and enable. cpu-panel is declarative; cpu-script runs in an isolated iframe and also needs Allow extension scripts. amber-theme adds a coordinated theme override; quiet-network adds a seeded preset. To remove an example, disable it in the manager and remove its installed folder from the configuration modules directory.

See docs/MODULE_API.md and the shared schemas for API details. These examples never execute shell commands or fetch network data.
