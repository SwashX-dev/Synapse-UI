# Changelog

## 3.0.0-alpha.1

- Modern Electron/TypeScript fork preserving eDEX history and GPL attribution.
- Removed unauthenticated localhost WebSocket shell transport; added validated IPC, isolated preload, application protocol and Electron hardening.
- Modular workspace with grid/freeform/hybrid editor, profiles, history, persistence and live themes.
- 15 visualization engines and 36 presets, Neural Sphere, worker generation, cameras, adaptive quality and capture tooling.
- Real PTYs, tabs/splits, authenticated terminal helper, system monitoring, configuration reload and sandboxed local extensions.
- Unit/Electron regression suites, cross-platform packaging workflows, Nix flake, documentation and examples.

This is an alpha; see docs/LIMITATIONS.md for compatibility and functional boundaries.
