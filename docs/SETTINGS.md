# Settings reference

Generated by `npm run docs:generate` from the runtime settings registry. Restart-required fields are marked.

| Key | Default | Description |
| --- | --- | --- |
| application.name | "SYNAPSE-UI" | Title shown in the window title bar and task switcher. |
| application.theme | "obsidian" | Active theme id. Built-in themes can be overridden by a file with the same id in themes/. |
| application.workspace | "neural-lab" | Active workspace profile id (a file in layouts/ or a built-in profile). |
| application.fullscreen | true | Run as a fullscreen workstation. Toggle at any time with F11. |
| application.frameless | false | Hide the operating-system window frame when windowed. **Restart required.** |
| application.display | -1 | Index of the monitor to open on (-1 = primary display). **Restart required.** |
| application.boot_animation | true | Play the eDEX-style boot log and logo animation on startup. |
| application.first_run_complete | false | Set to false to show the first-run setup again on next launch. |
| interface.scale | 1 | Zoom factor for the whole interface (useful on high-DPI or very large displays). |
| interface.panel_transparency | 0.1 | Additional transparency applied to every module background (0 = opaque theme value). |
| interface.animations_enabled | true | Enable panel transitions, glows and other interface motion (visualizations are controlled separately). |
| interface.reduced_motion | "system" | When reduced, interface transitions are disabled, automatic camera motion slows and visualizations run at half speed. |
| interface.show_titles | true | Show the thin technical title strip above each module. |
| interface.cursor_visible | true | Show the mouse cursor (eDEX-UI "nocursor" equivalent when disabled). |
| interface.notifications | true | Show transient notifications for configuration reloads, errors and command results. |
| interface.layout_mode | "hybrid" | Layout mode given to newly created workspaces. |
| interface.grid_snapping | true | Snap floating modules to grid lines and to the edges of other modules while editing. |
| interface.snap_threshold | 8 | Distance in pixels at which edges snap together. |
| performance.mode | "adaptive" | Eco minimises power, Cinematic maximises quality, Adaptive adjusts quality from measured frame times. |
| performance.target_fps | 60 | Upper bound for visualization frame rate. Individual modules may set lower limits. |
| performance.adaptive_quality | true | Automatically scale render resolution down when frames take longer than the budget, and back up when there is headroom. |
| performance.max_active_visualizations | 8 | Visualizations beyond this count (lowest priority first) are paused. |
| performance.suspend_hidden | true | Stop rendering visualizations that are off-screen, fully transparent, covered or in an inactive workspace. |
| performance.battery_saver | true | Switch to the Eco profile while running on battery power. |
| performance.show_fps | false | Display a frame-rate readout in each visualization HUD. |
| graphics.hardware_acceleration | true | Use the GPU. Disable only if your driver crashes; visualizations will be very slow without it. **Restart required.** |
| graphics.resolution_scale | 1 | Multiplier on device pixel ratio for all visualizations. |
| graphics.antialias | true | Multisample antialiasing for the shared WebGL renderer. Changing it reinitialises graphics. |
| graphics.power_preference | "high-performance" | Which GPU to request on hybrid-graphics laptops. Changing it reinitialises graphics. |
| graphics.ignore_gpu_blocklist | true | Allow GPU acceleration on drivers Chromium blocklists (eDEX-UI default; common on Linux). **Restart required.** |
| graphics.ozone_platform | "auto" | Select the Ozone platform on Linux. Automatic follows XDG_SESSION_TYPE. **Restart required.** |
| visualization.default_animation | "neural-sphere" | Preset used for newly added visualization modules. |
| visualization.quality | "auto" | Geometric complexity (node, particle and segment counts) of visualizations. |
| visualization.rotation_speed | 1 | Global multiplier for automatic camera orbiting. |
| visualization.time_scale | 1 | Global multiplier for simulation time in all visualizations. |
| visualization.glow | true | Hardware-accelerated bloom post-processing. |
| visualization.glow_strength | 1 | Global multiplier on bloom intensity. |
| visualization.motion_blur | false | Temporal accumulation (after-image) motion blur. |
| visualization.motion_blur_amount | 0.75 | How long previous frames persist. |
| visualization.hud | true | Overlay labels, statistics and callouts on visualizations. |
| visualization.seed | 1337 | Seed given to newly added visualizations (each module keeps its own seed). |
| terminal.default_shell | "auto" | "auto" uses $SHELL (or PowerShell on Windows). Otherwise a shell name on PATH or an absolute path. |
| terminal.shell_args | [] | Extra arguments passed to the shell. |
| terminal.login_shell | true | Start POSIX shells as login shells (-l) so your profile is loaded. |
| terminal.cwd | "" | Working directory for new terminals. Empty = home directory. |
| terminal.font_family | "" | Terminal font. Empty = the theme monospace font. |
| terminal.font_size | 13 | Terminal font size. |
| terminal.line_height | 1.1 | Terminal line height multiplier. |
| terminal.letter_spacing | 0 | Extra pixels between characters. |
| terminal.cursor_style | "block" | Shape of the terminal cursor. |
| terminal.cursor_blink | true | Blink the terminal cursor. |
| terminal.scrollback | 5000 | Lines of history kept per terminal. |
| terminal.renderer | "dom" | WebGL is faster for heavy output but uses one GPU context per terminal. |
| terminal.opacity | 1 | Terminal background opacity; lower values reveal visualizations behind floating terminals. |
| terminal.copy_on_select | false | Copy selected text to the clipboard automatically. |
| terminal.right_click_paste | false | Paste the clipboard on right click. |
| terminal.bell | "visual" | What happens when a program rings the terminal bell. |
| terminal.tab_title | "process" | What terminal tabs display. |
| terminal.app_commands | true | Expose the `synapse` command inside SYNAPSE-UI terminals to control the app (authenticated per session, no network socket). |
| terminal.env | {} | Extra environment variables for shells. |
| monitoring.enabled | true | Poll system statistics. When disabled, monitoring modules show no data. |
| monitoring.interval_scale | 1 | Multiplier for every polling interval (higher = less CPU, slower updates). |
| monitoring.temperature_unit | "c" | Unit for CPU and GPU temperatures. |
| monitoring.network_interface | "auto" | "auto" uses the default interface; or an interface name such as wlan0. |
| monitoring.process_limit | 40 | Maximum processes sent to the process monitor (sorted by the active column). |
| monitoring.clock_24h | true | Use a 24-hour clock in the clock module. |
| monitoring.gpu | true | Poll GPU statistics (spawns nvidia-smi on NVIDIA systems). |
| filesystem.show_hidden | false | Show dotfiles in the filesystem browser. |
| filesystem.list_view | false | Use a detailed list instead of the eDEX icon grid. |
| filesystem.follow_terminal | true | Filesystem browser follows the working directory of the focused terminal. |
| keyboard.layout | "en-US" | Layout used by the on-screen keyboard module. |
| keyboard.show_physical | true | Highlight on-screen keys when you press them on your physical keyboard. |
| audio.ui_sounds | true | Play the eDEX-UI interface sound effects. |
| audio.volume | 0.6 | Volume of interface sounds. |
| audio.feedback_sounds | false | Play sounds for keystrokes and terminal output. |
| audio.input_source | "none" | Source analysed for audio-reactive visualizations. Microphone and system audio require explicit permission each session. |
| audio.input_device | "default" | Input device id for microphone capture (on Linux, PipeWire/PulseAudio "Monitor of …" devices capture system output). |
| audio.file | "" | Last audio file used as the reactive source. |
| audio.gain | 1 | Amplification applied before frequency analysis. |
| audio.smoothing | 0.8 | Temporal smoothing of the frequency spectrum. |
| audio.beat_sensitivity | 1.35 | Energy ratio over the running average that counts as a beat (lower = more beats). |
| audio.monitor_file | true | Play audio files through the speakers while analysing them. |
| recording.output_dir | "" | Where screenshots and recordings are saved. Empty = Videos/SYNAPSE-UI (or Pictures for images). |
| recording.format | "webm" | Output format used by the record command. |
| recording.width | 0 | Output width in pixels for offline formats (0 = module size). |
| recording.height | 0 | Output height in pixels for offline formats (0 = module size). |
| recording.fps | 30 | Frames per second for recordings. |
| recording.duration | 10 | Length of recordings. |
| recording.quality | 0.9 | Bit-rate (WebM/MP4) or palette quality (GIF). |
| security.allow_extension_scripts | false | Allow third-party modules that declare the "script" permission to run JavaScript (each still needs individual approval). Declarative modules never need this. |
| security.external_links | "ask" | What happens when you click a URL in a terminal. |
| security.devtools | false | Allow opening Chromium developer tools (Ctrl+Shift+I). |
| advanced.log_level | "info" | Verbosity of the main-process log. |
| advanced.watch_config | true | Watch the configuration directory and apply external edits immediately. |
| advanced.backup_count | 20 | Number of automatic configuration backups to keep. |
| colors.background | "" | Overrides the active theme background for every workspace. Empty = theme value. |
| colors.foreground | "" | Overrides the theme foreground (lines, graph strokes). |
| colors.text | "" | Overrides the theme text color. |
| colors.accent | "" | Overrides the theme accent color. |
| colors.border | "" | Overrides the theme border color. |
| colors.glow | "" | Overrides the theme glow color. |
| colors.highlight | "" | Overrides the theme highlight color. |
| colors.neural | "" | Overrides neural connection color in visualizations. |
| colors.particle | "" | Overrides particle color in visualizations. |
